# 🎮 Number Guessing Game

A simple beginner-friendly Python project where the computer selects a random number between 1 and 100, and the player tries to guess it.

## 🐍 Technologies Used

* Python
* Random module

## ✨ Features

* Generates a random number between 1 and 100
* Takes guesses from the user
* Tells the user if the guess is too high or too low
* Displays a success message when the correct number is guessed

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or Terminal.
4. Run the following command:

```bash
python guessing_game.py
```

## 🎯 How to Play

1. The computer selects a random number between 1 and 100.
2. Enter your guess.
3. The game will tell you:

   * **Too low** – your guess is smaller than the number.
   * **Too high** – your guess is larger than the number.
   * **Correct** – you guessed the number!

